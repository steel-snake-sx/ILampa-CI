# ILampa CI Lab

Public clean-source snapshot and GitHub Actions test lab for experimental ILampa iOS builds.

Source baseline: `steel-snake-sx/ILampa` / `integration/2.2.0` / `f597d120a5137379af79cfdb3b636e1b2a916d74`.

This public repository intentionally excludes the original private Git history, internal reports and signing credentials. Experiments live in separate `experiment/2.3.0-*` branches. Builds are unsigned arm64 IPA artifacts with iOS simulator test evidence.

The application contains upstream Lampa/ByLampa components; upstream GPL-2.0 license texts are retained under `LICENSES/`, alongside ILampa's existing `LICENSE`. No endorsement by upstream maintainers is implied. Review combined licensing requirements before distributing a public release.
